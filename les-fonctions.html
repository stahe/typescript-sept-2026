    8. Les fonctions

    Les scripts de ce chapitre se trouvent dans le dossier [fonctions] du projet.

    8.1. script [func-01]

    Ce script s'intéresse au mode de passage des paramètres d'une fonction : par valeur pour les nombres, chaînes et booléens ; par référence pour les tableaux, objets littéraux et fonctions.

      1  'use strict';
  2  // mode de passage des paramètres d'une fonction
  3  // -----------------------nombre - passage par valeur
  4  function doSomethingWithNumber(param: number): void {
  5    param++;
  6    console.log("[param inside function]=", param, "[type]=", typeof (param), "[passage par référence]=", param === count);
  7  }
  8  // code d'appel
  9  let count: number = 10;
 10  doSomethingWithNumber(count);
 11  console.log("[count outside function]=", count);
 12  
 13  // --------------------- chaîne - passage par valeur
 14  function doSomethingWithString(param: string): void {
 15    param += " xyz"
 16    console.log("[param inside function]=", param, "[type]=", typeof (param), "[passage par référence]=", param === text);
 17  }
 18  // code d'appel
 19  let text: string = "abcd";
 20  doSomethingWithString(text);
 21  console.log("[text outside function]=", text);
 22  
 23  // --------------------- booléen - passage par valeur
 24  function doSomethingWithBoolean(param: boolean): void {
 25    param = !param;
 26    console.log("[param inside function]=", param, "[type]=", typeof (param), "[passage par référence]=", param === bool);
 27  }
 28  // code d'appel
 29  let bool: boolean = true;
 30  doSomethingWithBoolean(bool);
 31  console.log("bool [outside function]=", bool);
 32  
 33  // --------------------- tableau - passage par référence
 34  function doSomethingWithArray(param: number[]): void {
 35    param.push(1000);
 36    console.log("[param inside function]=", param, "[type]=", typeof (param), "[passage par référence]=", param === tab);
 37  }
 38  // code d'appel
 39  const tab: number[] = [10, 20, 30];
 40  doSomethingWithArray(tab);
 41  console.log("[tab outside function]=", tab);
 42  
 43  // --------------------- objet - passage par référence
 44  // [any] pour pouvoir ajouter dynamiquement [unePropriétéNouvelle], comme en JS
 45  function doSomethingWithObject(param: any): void {
 46    param.unePropriétéNouvelle = "xyz";
 47    console.log("[param inside function]=", param, "[type]=", typeof (param), "[passage par référence]=", param === obj);
 48  }
 49  // code d'appel
 50  const obj: any = [10, 20, 30];
 51  doSomethingWithObject(obj);
 52  console.log("[obj outside function]=", obj);
 53  
 54  // --------------------- fonction - passage par référence
 55  // [any] car on attribue dynamiquement une propriété à la fonction elle-même (cf plus bas)
 56  function doSomethingWithFunction(param: any): void {
 57    // une chose plutôt bizarre qui marche pourtant
 58    param.unePropriétéNouvelle = "xyz";
 59    console.log("[param inside function]=", param, "[type]=", typeof (param), "[passage par référence]=", param === f);
 60  }
 61  // code d'appel
 62  const f: any = (x: number) => x + 4;
 63  doSomethingWithFunction(f);
 64  console.log("[f outside function]=", f, f.unePropriétéNouvelle, typeof (f));
    • les types primitifs (number, string, boolean) sont passés par valeur : modifier param à l'intérieur de la fonction ne modifie jamais la variable d'origine (passage par référence = false dans chaque cas) ;
    • les tableaux, objets et fonctions sont passés par référence : param === tab (ou obj, ou f) vaut true, et une modification à l'intérieur de la fonction est bien visible à l'extérieur ;
    • ligne 41 : function doSomethingWithObject(param: any) — typé any car on ajoute dynamiquement une propriété (unePropriétéNouvelle) non prévue dans le type d'origine du tableau obj ;
    • ligne 51 : même chose pour doSomethingWithFunction — on ajoute une propriété à la fonction elle-même, un comportement JavaScript un peu déroutant mais parfaitement valide (une fonction est aussi un objet).
    npx tsx fonctions/func-01.ts

    Résultat de l'exécution :

      1  [param inside function]= 11 [type]= number [passage par référence]= false
  2  [count outside function]= 10
  3  [param inside function]= abcd xyz [type]= string [passage par référence]= false
  4  [text outside function]= abcd
  5  [param inside function]= false [type]= boolean [passage par référence]= false
  6  bool [outside function]= true
  7  [param inside function]= [ 10, 20, 30, 1000 ] [type]= object [passage par référence]= true
  8  [tab outside function]= [ 10, 20, 30, 1000 ]
  9  [param inside function]= [ 10, 20, 30, 'unePropriétéNouvelle': 'xyz' ] [type]= object [passage par référence]= true
 10  [obj outside function]= [ 10, 20, 30, 'unePropriétéNouvelle': 'xyz' ]
 11  [param inside function]= [Function: f] { 'unePropriétéNouvelle': 'xyz' } [type]= function [passage par référence]= true
 12  [f outside function]= [Function: f] { 'unePropriétéNouvelle': 'xyz' } xyz function

    8.2. script [func-02]

    Ce script montre que [function] est un type de donnée comme un autre : une variable peut avoir ce type, et il existe deux façons de définir une fonction — avec le mot clé function, ou avec la notation fléchée =>.

      1  'use strict';
  2  // on peut affecter une fonction à une variable
  3  const variable1: (a: number, b: number) => number = function (a, b) {
  4    return a + b;
  5  };
  6  console.log("typeof(variable1)=", typeof (variable1));
  7  // la variable peut ensuite s'utiliser comme une fonction
  8  console.log("variable1(10,12)=", variable1(10, 12));
  9  // la définition de la fonction peut se faire avec la notation =>
 10  const variable2: (a: number, b: number, c: number) => number = (a, b, c) => {
 11    return a - b + c;
 12  };
 13  console.log("variable2(10,12,14)=", variable2(10, 12, 14));
 14  // on peut ne pas mettre les accolades s'il n'y a qu'une expression dans le code de la fonction
 15  // cette expression est alors la valeur de retour de la fonction
 16  const variable3 = (a: number, b: number, c: number): number => a + b + c;
 17  console.log("variable3(10,12,14)=", variable3(10, 12, 14));
    • ligne 3 : const variable1: (a: number, b: number) => number = function (a, b) {...} — le type d'une variable-fonction se déclare comme une signature (paramètres) => typeDeRetour ;
    • lignes 10-12 : la même chose avec la notation fléchée (a, b, c) => { ... } ;
    • ligne 16 : sans accolades, le corps de la fonction se réduit à une seule expression, qui devient automatiquement la valeur de retour — (a, b, c): number => a + b + c.
    npx tsx fonctions/func-02.ts

    Résultat de l'exécution :

      1  typeof(variable1)= function
  2  variable1(10,12)= 22
  3  variable2(10,12,14)= 12
  4  variable3(10,12,14)= 36

    8.3. script [func-03]

    Ce script montre qu'une fonction peut être passée en paramètre à une autre fonction — un procédé très utilisé dans les frameworks TypeScript/JavaScript (callbacks, map/filter/reduce du chapitre « Les tableaux »...) :

      1  'use strict';
  2  // les paramètres d'une fonction peuvent être de type [fonction]
  3  
  4  // fonction f1
  5  function f1(param1: number, param2: number): number {
  6    return param1 + param2 + 10;
  7  }
  8  // fonction f2
  9  function f2(param1: number, param2: number): number {
 10    return param1 + param2 + 20;
 11  }
 12  // fonction g avec une fonction f en paramètre
 13  function g(param1: number, param2: number, f: (a: number, b: number) => number): number {
 14    return f(param1, param2) + 100;
 15  }
 16  // utilisations de g
 17  console.log(g(0, 10, f1));
 18  console.log(g(0, 10, f2));
 19  // le paramètre effectif de type fonction peut être passé en direct - forme 1
 20  console.log(g(0, 10, (param1, param2) => {
 21    return param1 + param2 + 30;
 22  }));
 23  // le paramètre effectif de type fonction peut être passé en direct - forme 2
 24  console.log(g(0, 10, function (param1, param2) {
 25    return param1 + param2 + 40;
 26  }));
    • ligne 13 : function g(param1: number, param2: number, f: (a: number, b: number) => number): number — le 3ᵉ paramètre f est lui-même typé comme une fonction ;
    • lignes 20-22 et 24-26 : le paramètre effectif de type fonction peut être passé directement, sous forme fléchée ou classique, sans être d'abord stocké dans une variable.
    npx tsx fonctions/func-03.ts

    Résultat de l'exécution :

      1  120
  2  130
  3  140
  4  150

    8.4. script [func-04]

    Ce script montre qu'une fonction peut se comporter comme une classe — un mécanisme antérieur à ES6 mais toujours valide, bien que remplacé aujourd'hui par le mot clé class (voir chapitre « Les classes ») :

      1  'use strict';
  2  // une fonction peut être utilisée comme un objet
  3  
  4  // une coquille vide
  5  // [any] : le type de [this] est ici volontairement souple, car on attribue
  6  // des propriétés à la fonction elle-même APRÈS sa définition (cf plus bas) -
  7  // un schéma que TypeScript ne peut pas déduire tout seul
  8  function f(this: any): void {
  9  
 10  }
 11  // à qui on attribue des propriétés de l'extérieur
 12  (f as any).prop1 = "val1";
 13  (f as any).show = function (this: any) {
 14    console.log(this.prop1);
 15  };
 16  // utilisation de f
 17  (f as any).show();
 18  
 19  // une fonction g fonctionnant comme une classe
 20  function g(this: any): void {
 21    this.prop2 = "val2";
 22    this.show = function (this: any) {
 23      console.log(this.prop2);
 24    };
 25  }
 26  // instanciation de la fonction avec [new]
 27  new (g as any)().show();
    • lignes 5-9 : f est une fonction « coquille vide », typée this: any — cette annotation spéciale du premier paramètre indique à TypeScript le type de this à l'intérieur de la fonction, nécessaire ici car des propriétés lui sont ajoutées de l'extérieur, un schéma que TypeScript ne peut pas déduire seul ;
    • lignes 12-15 : on donne, depuis l'extérieur, des propriétés à f — (f as any).prop1 = ... ;
    • ligne 17 : on appelle f.show(), et non f() — c'est bien la notation d'utilisation d'un objet, pas d'un appel de fonction classique ;
    • lignes 20-27 : g définit this.prop2 et this.show en son sein, comme le ferait un constructeur de classe ;
    • ligne 29 : new (g as any)() instancie g comme une classe.
    npx tsx fonctions/func-04.ts

    Résultat de l'exécution :

      1  val1
  2  val2
    Remarque : ES6 a introduit le mot clé class (voir chapitre « Les classes »), qui permet d'obtenir directement ce résultat sans passer par ce détour fonctionnel.

    8.5. script [func-05]

    Ce script montre l'usage du [rest operator] (...), qui rassemble tous les arguments restants d'un appel dans un tableau :

      1  'use strict';
  2  // rest operator
  3  function f(arg1: number, ...otherArgs: unknown[]): void {
  4    // 1er argument
  5    console.log("arg1=", arg1);
  6    // les autres arguments
  7    let i = 0;
  8    otherArgs.forEach(element => {
  9      console.log("otherArguments[", i, "]=", element);
 10      i++;
 11    });
 12  }
 13  
 14  // appel
 15  f(1, "deux", "trois", { x: 2, y: 3 })
    • ligne 3 : function f(arg1: number, ...otherArgs: unknown[]): void — otherArgs rassemble tous les arguments passés après arg1, quel que soit leur nombre. Le type unknown[] est adapté ici puisque otherArgs mélange volontairement des types différents (chaînes et objet, dans l'appel de la ligne 15).
    npx tsx fonctions/func-05.ts

    Résultat de l'exécution :

      1  arg1= 1
  2  otherArguments[ 0 ]= deux
  3  otherArguments[ 1 ]= trois
  4  otherArguments[ 2 ]= { x: 2, y: 3 }
